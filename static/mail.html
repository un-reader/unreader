MAIL SETUP HELP

      
Choose IMAP or POP3, select a provider preset, then enter your full email address and provider-approved password. This app connects over secure IMAP port 993 or POP3 port 995.

      
Gmail

      
Enable the protocol you selected in Gmail’s Forwarding and POP/IMAP settings. Use imap.gmail.com:993 or pop.gmail.com:995. If Google rejects your regular password, use an App Password (requires 2-Step Verification). OAuth sign-in is not supported by this app.

      
Yahoo Mail

      
Use imap.mail.yahoo.com:993 or pop.mail.yahoo.com:995, your full email address, and a generated Yahoo app password.

      
Outlook.com / Hotmail

      
Choose Outlook.com and press SIGN IN WITH MICROSOFT. The sign-in code is handled by Microsoft and used to connect over IMAP. POP3 sign-in is not supported. IMAP access may need to be enabled in Outlook settings.

      
iCloud Mail

      
iCloud supports IMAP only: imap.mail.me.com:993. Use an Apple app-specific password; POP3 is not available.

      
Proton Mail

      
Proton does not provide direct IMAP or POP3 access. Its supported mail-client setup uses Proton Mail Bridge, which runs on your computer and exposes IMAP only to local apps. This app’s mail connection runs on the server, so it cannot reach Bridge on your computer. The Microsoft OAuth example in ReKindle does not apply to Proton.

      
Other providers

      
Select Custom and enter the mail server provided by your service. The server must support implicit TLS on port 993 for IMAP or 995 for POP3. Some work or school accounts require administrator setup or OAuth and cannot connect with this app.

      
If a server rejects access, its response appears in the MAIL SERVER RESPONSE panel. For example, a POP-disabled error means POP access must be enabled in that provider’s settings.
