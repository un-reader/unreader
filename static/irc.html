IRC CLIENT

Connect to any public IRC network that supports TLS. Enter its server hostname, a supported TLS port (6665–6669, 6697, 7000, or 7070), your nickname, and an optional channel. The presets are examples; choose Custom network for any other server. This client never falls back to plaintext. Messages pass through Un-Reader’s TLS bridge and chat history stays in page memory. The IRC network sees the bridge server’s IP, not your device’s IP; other users may see the host or cloak that network assigns. Server passwords are used for this connection only.

USERS

Join a channel to see its users.

Commands: /join #channel, /part, /nick name, /msg nick text, /query nick, /me action, /topic text, /names, /whois nick, /invite nick, /kick nick [reason], /away message, /quit. Click a name in the user list to open a private message.
