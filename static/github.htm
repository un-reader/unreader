GitHub Token Auth

GitHub tokens are encrypted in this browser with your PIN before upload. The PIN is never sent to the server. If you used the old local or account save, enter that key above, select Save Key, and choose a PIN to migrate it; the old copy is cleared after the encrypted save succeeds. Without Save Key, the token is kept in memory for this visit only.
